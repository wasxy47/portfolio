---

## 🎨 Theme & Aesthetics (The Cyber-Crimson Vibe)

The UI/UX is built around a **Dark Terminal & Holographic** aesthetic. 

- **Primary Background:** **Deep Void / Pitch Black (`#0f0f0f` & `#000000`)** - Represents the terminal and backend environment.
- **Primary Accent:** **Blood Red / Crimson (`#ff0000` / `#f20505`)** - Used for glowing overlays, text highlights, glowing borders, and the GitHub contribution heatmap.
- **Lighting & Depth:** Extensive use of CSS `box-shadow` and `translateZ()` to create a 3D glassmorphic and glowing neon effect.

**Unique Styling Hacks:**
To maintain the strict dark-red theme without compromising third-party APIs (like the GitHub contribution grid), advanced CSS Data Manipulation was used:
> `filter: invert(0.87) hue-rotate(180deg) saturate(2.5) brightness(0.7) contrast(1.4);`
This seamlessly transforms bright white images into deep dark elements with striking red data points.

## ✨ Core Features

- 🌐 **Interactive 3D Elements:** Features a fanned deck for project cards, rotating 3D skill globes, and holographic floating datapads for the "System History" timeline.
- 📡 **Live GitHub Stats:** Dynamic injection of GitHub activity graphs and Contribution Grids with forced dark-mode processing.
- 💻 **Terminal-Style Contact Form:** A "Secure Uplink" contact section with a radar scanner and encrypted transmission vibe.
- 🧠 **Neural Backgrounds:** Animated HTML5 Canvas backgrounds simulating neural networks and cursor-following particles.
- ⚡ **High Performance:** Smooth scroll, AOS (Animate On Scroll) transitions, and highly optimized asset delivery.

## 🛠️ Tech Stack

- **Markup & Styling:** HTML5, CSS3 (Advanced @keyframes, 3D Transforms, Custom Properties)
- **Scripting:** Vanilla JavaScript (ES6+), jQuery
- **Libraries/Plugins:** 
  - `AOS.js` for scroll animations
  - `Typed.js` for terminal typing effects
  - `TagCloud.js` for the 3D spherical skills view
- **Icons & Typography:** FontAwesome 6, Google Fonts (Poppins, Anton)

## 💻 How to Run Locally

If you want to boot up this system on your local machine:

1. Clone or download the repository.
2. Navigate to the project folder in your terminal.
3. Start a local server (Python 3 recommended):
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and navigate to: `http://localhost:8000`
